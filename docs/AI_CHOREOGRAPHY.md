# 音乐生成全身舞蹈

当前编辑器尚未集成训练好的音乐生成舞蹈模型。节拍和歌词驱动的规则试作只用于验证工程、音频和动作轨道流程，不应视为高质量 AI 编舞。

| 候选 | 输出与能力 | 接入需要解决的问题 |
| --- | --- | --- |
| [EDGE](https://github.com/Stanford-TML/EDGE) | 音乐条件扩散生成全身三维舞蹈，支持关节约束、补间与动作续接；官方提供动作保存及 SMPL 到 FBX 的转换路线 | 独立 Python / PyTorch 推理环境、音乐特征提取、权重下载、SMPL 到角色静止姿态重定向；源码为 MIT |
| [LODGE](https://github.com/li-ronghui/LODGE) | 全局与局部两阶段扩散生成长段舞蹈，并细化脚部接触 | FineDance 骨架到 Unity / MMD 的映射、地面接触、时间轴对齐与独立推理环境；使用前应核对代码、数据及权重许可 |

这两种方案确实输出全身骨骼动作，但不保证自动匹配所有角色、服装或音乐。需要将根节点、髋部、脊柱、四肢和脚部一起重定向，校准身高、静止姿态、单位和朝向，并在目标骨架上处理脚滑和穿模。不能仅复制旋转数值或替换手臂轨道。

建议接入流程：本地音乐 → 独立 GPU 推理 → 原始 SMPL / FineDance 动作 → 骨架重定向与接地 → 编辑器原生骨骼 JSON / VMD → 手动修整。生成模型与 MediaPipe 视频动捕属于不同功能，目前发布包只包含后者。

ComfyUI 文生视频可以生成画面；若需要可编辑模型动作，还需要从结果视频重新进行姿态识别。相比直接生成三维骨骼，这一步会引入遮挡、深度和多人身份误差。这是根据两种输出形式做出的工程判断。
