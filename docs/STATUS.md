## 已知问题

- 布料采用离散顶点/三角面接触，未实现连续边/边碰撞、完整厚壳布料或跨角色全身碰撞；不能保证极端动作完全不穿模。配饰接触检测链端点；手臂约束只覆盖躯干/腿部接触。
- 均衡档对没有身体修正、只有一层布面的原生动作保留原服装姿态；高精度档每帧检查自碰撞。PMX 刚体为骨骼胶囊/球的基础近似，仍需在 MMD / PMX Editor 核对形状、碰撞组和刚度。
- VMD 不提供源模型静止骨架；动作来自不同骨架时，可能需要源 PMX 校准和手工调整。
- 部分模型只提供局部骨架；缺失关节和表情不会由动捕凭空补出。
- 单目视频深度是估计值；遮挡、交叉、切镜、快速运动和远处手指/面部会降低结果质量。位置/速度跟踪可能交换人物身份。
- 网页舞台不运行原游戏的全部专用脚本、Shader、动态光照与后处理；相机还原需要源数据完整。
- NVENC 加速编码，流水线重叠快照压缩与上传；WebGL 绘制与物理仍按顺序运行。
- Unity 验证限 2022.3 内置渲染管线；URP/HDRP 材质尚未适配。网页灯具柔光并非原游戏专用 Shader 和调度的像素级复现。
- 浏览器视频动捕结果已能保存和编辑，但仍应按使用者自己的拍摄视频核对动作准确度。
- 一次单人编舞浏览器测量约 57 fps；五人完整布料接触的 CPU 开销明显增加，不保证实时 60 fps。离线导出保留全部帧。桌面封装本身不会消除物理计算成本；当前继续使用浏览器。
- 本地音乐编舞试作由节拍分析与编排规则生成可编辑关键帧；不是训练好的音乐生成舞蹈模型，歌词段落时间是初估，口型不是音素对齐。
- GitHub 更新需要仓库有正式 Release；没有时明确显示状态。尚未执行真实线上版本替换。
