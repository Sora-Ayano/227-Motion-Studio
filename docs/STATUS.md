# 开发状态

本文件区分已经实现、仍有限制和待开发的功能；不以功能开关的存在代替完整验证。

## 已实现

- 保留 Unity 原生骨骼和蒙皮；MMD / Unity / Mixamo 骨骼映射与源骨架校准。
- 模型与贴图导入、原生角色组件库、服装配饰、独立五人换装与位置调整。
- 身体、表情、相机、音频独立轨道；内置动作可编辑并保存；轨道独立清除与新工程。
- 原生歌曲的站位、角色位移及相机挂点适配；舞台、背景和灯光读取。
- 柔光、环境补光、滤镜、泛光、景深、绿幕及全屏预览。
- 布料约束、腿部胶囊碰撞、头发与领带等辅助动态；任意跳转时重置惯性。
- 固定时间逐帧 MP4、可选音频、NVIDIA 编码探测与 CPU 回退、多帧上传编码流水线。
- Heavy / Full 人体检测与面部表情检测，按目标关节静止轴向、层级和肢体长度适配。
- 带贴图及自定义配饰的 GLB / PMX / Unity 包导出、指定保存位置与关闭本机服务。

## 已知问题

- 布料尚无完整自碰撞、多层衣物接触及布料与全部配饰的网格碰撞；不能保证任意动作完全不穿模。
- VMD 不提供源模型静止骨架；动作来自不同骨架时，可能需要源 PMX 校准和手工调整。
- 部分模型只提供局部骨架；缺失关节和表情不会由动捕凭空补出。
- 单目视频深度是估计值；遮挡、快速运动与远处面部会降低动捕质量。当前提取一位人物，手指尚无独立精细跟踪。
- 网页舞台不运行原游戏的全部专用脚本、Shader、动态光照与后处理；相机还原需要源数据完整。
- NVENC 加速编码，流水线重叠快照压缩与上传；WebGL 绘制与物理仍按顺序运行。
- PMX 模型包未自动生成刚体和物理关节；Unity 导入器尚待真实 Unity Editor 编译与预览验证。
- 浏览器视频动捕结果已能保存和编辑，但仍应按使用者自己的拍摄视频核对动作准确度。
